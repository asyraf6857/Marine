# VTMS Marine Simulator & Consultant

Interactive marine planning workspace for Tanjung Pelepas.

## V1.1
- Nautical/bathymetry-first map view
- DD + DMM cursor coordinates
- Editable drawings, buoys and dedicated Wharf/Berth Editor
- Wharf metadata: name, berth ID, depth alongside and notes
- Vessel movement simulation with speed, heading and rudder
- Simplified wind/current/tug effects
- Static UKC monitoring and target CPA/TCPA
- Browser scenario save/load
- GeoJSON export and planning report

## Wharf workflow
Enter wharf metadata, click **Draw New Wharf**, click points along the wharf footprint and double-click to finish. Use **Edit Marine Objects** to move vertices later. Wharf objects are included in Save and GeoJSON export.

> Planning/reference use only. Not a substitute for official ENC, hydrographic survey data, pilotage requirements, or a certified full-mission bridge simulator.
